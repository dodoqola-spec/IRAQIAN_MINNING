# IRAQIAN MINNING PRO

نسخة Node.js + PostgreSQL قابلة للنشر، مع تدفقات حقيقية للإيداع والسحب اليدوي.

## ما تم إصلاحه
- USDT decimals تُقرأ من عقد التوكن على الشبكة بدل افتراض 6؛ لذلك يدعم BSC USDT بشكل صحيح.
- TXID الإيداع يُفحص on-chain، ثم يبقى `pending` إلى أن يوافق الأدمن يدويًا.
- عند موافقة الأدمن فقط يُضاف مبلغ الإيداع إلى رصيد المستخدم.
- رفض الإيداع لا يضيف أي رصيد.
- السحب يحجز الرصيد داخل transaction، والرفض يعيد الرصيد.
- عند تسجيل دفع السحب، يتم فحص TXID on-chain والتأكد من نجاح المعاملة ووصول USDT إلى عنوان المستلم بالمبلغ المطلوب قبل وضع الحالة `paid`.
- منع إعادة استخدام TXID للسحب.
- شراء الاشتراك يتم من رصيد المستخدم ويُنشئ مدة اشتراك فعلية 30 يومًا حسب الخطة.
- صلاحيات user/admin، Argon2، HttpOnly sessions، rate limiting، Helmet، audit log.

## الخطط
5 / 10 / 20 / 50 / 100 / 200 / 300 / 400 / 500 USDT، مدة 30 يومًا.

## المحافظ
Polygon USDT وBEP20 USDT يستخدمان العنوان الموجود في `.env.example`.

## التشغيل محليًا
1. Node.js 20+ وPostgreSQL.
2. `npm install`
3. لقاعدة جديدة: نفّذ `schema.sql`.
4. لقاعدة النسخة القديمة: نفّذ `MIGRATION.sql` أولًا.
5. انسخ `.env.example` إلى `.env`.
6. غيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD` وبيانات قاعدة البيانات.
7. شغّل `npm start`.
8. افتح `http://localhost:3000`.

## النشر
المشروع مناسب لخدمات Node.js التي توفر PostgreSQL وHTTPS. أضف متغيرات البيئة كما في `.env.example`، ثم شغّل `npm start`.

## أمان مهم
- لا تضع private key أو seed phrase في السيرفر.
- السحب يدوي من محفظتك؛ السيرفر لا يحتفظ بالمفاتيح الخاصة.
- استخدم HTTPS في الإنتاج.
- استخدم RPC موثوقًا وراقب الأخطاء والنسخ الاحتياطية.
- غيّر كلمة مرور الأدمن الافتراضية فورًا.
- قبل استقبال أموال الجمهور، راجع متطلبات KYC/AML والضرائب والقوانين المحلية.
- لا تعرض عوائد مضمونة أو أرباح تعدين غير حقيقية.
